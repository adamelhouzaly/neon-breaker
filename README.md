# Neon Breaker

Neon Breaker is a brick breaker game I made using HTML, CSS, and JavaScript. I wanted to make a classic arcade game but give it a neon look and add features that make it more fun than a basic Breakout game.

The goal is simple: keep the ball from falling, break all the bricks, collect power-ups, and try to get the highest score.

## How to Play

- Use `A` or the `Left Arrow` key to move left
- Use `D` or the `Right Arrow` key to move right
- Press `Space` to launch the ball

You can also use the buttons on the screen if you are playing on a phone or tablet.

## What I Added

- Different levels that get harder as you play
- A score, lives, level counter, and saved high score
- Bricks that take one hit to break
- Armored bricks that take two hits
- Explosive bricks that can destroy nearby bricks
- A `W` power-up that makes the paddle wider for a few seconds
- An `M` power-up that gives you multiple balls
- Particle effects and screen shake when explosive bricks break
- Keyboard and mobile controls
- A neon arcade-style design

## Files in This Project

- `index.html` is the main page for the game
- `style.css` is where I made the design and layout
- `game.js` has all of the game code, including movement, collisions, power-ups, scoring, and levels

## Things I Practiced

While making this game, I practiced:

- Using JavaScript to make a real-time game loop
- Detecting collisions between the ball, paddle, walls, and bricks
- Making the ball bounce in different directions depending on where it hits the paddle
- Using arrays to manage bricks, balls, particles, and power-ups
- Saving the high score in the browser with `localStorage`
- Making the game work on both desktop and mobile screens

## How to Run It

1. Download or clone the repository
2. Make sure `index.html`, `style.css`, and `game.js` are in the same folder
3. Open `index.html` in your browser
4. Click **Start Game** and press `Space` to begin
